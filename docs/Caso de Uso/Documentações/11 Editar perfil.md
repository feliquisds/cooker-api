Apresenta edição do perfil

**Atores:** Usuário logado  
**Descrição:** Realiza a edição dos dados do próprio perfil  
**Pré-condições:** Usuário deve estar autenticado  
**Pós-condições:** Dados do perfil são atualizados  
**Referências:** RF01, RF10, RNF02, RNF03, RN01, RN03, RN04  

**Fluxo básico:**  
    1. Usuário acessa a edição de perfil  
    2. Sistema apresenta os dados atuais  
    3. Usuário altera as informações desejadas  
    4. Sistema salva as alterações  

**Fluxos de exceção:**  
    **Dados inválidos:**  
        1. Fluxo é interrompido  
        2. É exibido mensagem de erro apropriada

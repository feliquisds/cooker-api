Realiza criação de solicitação de receita

**Atores:** Usuário logado  
**Descrição:** Realiza a criação de uma solicitação de receita  
**Pré-condições:** Usuário deve estar autenticado  
**Pós-condições:** Solicitação de receita é criada  
**Referências:** RF08, RNF02, RNF03, RN03, RN04  

**Fluxo básico:**  
    1. Usuário acessa a criação da solicitação  
    2. Sistema apresenta o formulário  
    3. Usuário informa os dados da solicitação  
    4. Sistema salva a solicitação  
    5. Sistema prepara notificação
